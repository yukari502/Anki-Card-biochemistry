### Front
名词解释：糖酵解

### Back
指无氧条件下，1分子葡萄糖在细胞胞浆中转变为2分子丙酮酸并净生成2分子 ATP 和 2分子 NADH 所经历的一系列反应过程。它是生物体共有的葡萄糖分解代谢的前期途径。

---
### Front
名词解释：无效循环

### Back
指生物组织内由两个不同的酶催化两个相反的代谢途径（单向反应），反应的一方需要高能化合物（如 ATP）参与，而另一方则自动水解。这种互变循环的结果只是高能化合物（ATP）被水解产生能量（热能），而底物并无净变化。又称无用循环，其基础是底物循环。

### Front
名词解释：巴斯德效应与反巴斯德效应

### Back
* **巴斯德效应（Pasteur效应）：** 指在有氧条件下，糖的有氧氧化对糖酵解（无氧氧化/发酵）的抑制作用。表现为有氧时葡萄糖的消耗速度和酵解速度显著减慢。
* **反巴斯德效应（反Pasteur作用 / Crabtree效应）：** 指一些组织细胞（如癌细胞及部分正常组织细胞）在给予高浓度葡萄糖时，无论供氧充足与否，均呈现极强的酵解（无氧氧化）反应，而糖的有氧氧化受到抑制的现象。

---

### Front
名词解释：瓦博格效应

### Back
瓦博格效应是指：即使在氧气充足的情况下，癌细胞也更倾向于通过高能耗、低效率的“有氧糖酵解”来消耗葡萄糖并产生乳酸，而不是像正常细胞那样通过线粒体进行高效的有氧呼吸

在癌细胞活跃的原因主要有
1. 糖酵解可以作为中间产物分流到其他代谢如PPP，用于大量合成核苷酸、氨基酸、脂质。
2. 糖酵解虽然转化效率低但是速率快，能快速满足癌细胞能量需求
3. 肿瘤生长往往会使内部处于缺氧环境，故EMP作为优势
4. 抑癌基因失活会上调EMP关键基因的表达。

### Front
名词解释：底物水平磷酸化 与 中间产物磷酸化

### Back
* **底物水平磷酸化：** 指在代谢途径中，底物因脱氢或脱水等反应形成高能代谢物，并在酶的催化下直接将高能磷酸基团转移给 \(ADP\)（或 \(GDP\)）生成 \(ATP\)（或 \(GTP\)）的不需氧过程。
* **中间产物磷酸化：** 指糖酵解等代谢途径中，由葡萄糖到所有中间产物都以磷酸化化合物形式实现的现象。其生理学意义在于：
  1. 带有负电荷的磷酸基团使中间产物具有极性，使其不易透过脂膜流失；
  2. 磷酸基团作为酶反应的识别信号基团，有利于底物与酶结合并被催化；
  3. 便于在酵解后期将高能磷酸基团转移给 \(ADP\) 形成 \(ATP\)，起到保存能量的作用。

### Front
名词解释：砷酸解偶联作用

### Back
指在糖酵解（EMP途径）中，**砷酸盐**由于结构类似于**无机磷酸**（\(P_i\)），在**3-磷酸甘油醛氧化生成1,3-二磷酸甘油酸**的步骤中，替代了**无机磷酸** \(P_i\) 参与反应，生成极不稳定的中间体**1-砷酸-3-磷酸甘油酸**。该中间体迅速自发水解为3-磷酸甘油酸，使得酵解反应虽能继续进行，但损失了通过底物水平磷酸化产生 \(ATP\) 的高能磷酸键，从而使该氧化步骤与磷酸化产生解偶联的现象。

### Front
名词解释：氟化物的抑制作用（氟化物对糖酵解的抑制机制）

### Back
氟化物是糖酵解途径中**烯醇化酶**（enolase）的强烈**抑制剂**。
* **抑制机制**：烯醇化酶在结合底物前，必须先与两价金属阳离子（如 \(Mg^{2+}\) 或 \(Mn^{2+}\)）结合形成复合物才能表现出催化活性。氟离子（\(F^-\)）会与 \(Mg^{2+}\) 及无机磷酸结合形成一个复合物，**取代了酶分子上原先 \(Mg^{2+}\) 的结合位置**，从而使该酶失活，阻断2-磷酸甘油酸向磷酸烯醇式丙酮酸（PEP）的转化。
* **应用**：测定血糖浓度之前，常在血样中加入少量氟化钠以阻止糖酵解的进行，确保测定结果的准确性。

### Front
论述：简述糖酵解的过程、关键酶及生理意义

### Back
* **亚细胞定位**：细胞的**细胞质基质（胞液）**。
* **底物简称对照**：葡萄糖（G）、6-磷酸葡萄糖（G-6-P）、6-磷酸果糖（F-6-P）、1,6-二磷酸果糖（F-1,6-BP）、磷酸二羟丙酮（DHAP）、3-磷酸甘油醛（GAP）、1,3-二磷酸甘油酸（1,3-BPG）、3-磷酸甘油酸（3-PG）、2-磷酸甘油酸（2-PG）、磷酸烯醇式丙酮酸（PEP）、丙酮酸（Pyr）。
* **糖酵解反应过程（由 10 步酶促反应组成）**：
 **1. 准备阶段（耗能阶段，G 转化为 2分子 GAP）**
- **第1步：G的磷酸化（不可逆）**
  \[\text{G} + \text{ATP} \xrightarrow{\text{己糖激酶（限速酶）/Mg}^{2+}} \text{G-6-P} + \text{ADP} + \text{H}^+\]
- **第2步：G-6-P的异构化**
  \[\text{G-6-P} \xrightleftharpoons{\text{磷酸葡萄糖异构酶}} \text{F-6-P}\]
- **第3步：F-6-P的磷酸化（不可逆）**
  \[\text{F-6-P} + \text{ATP} \xrightarrow{\text{磷酸果糖激酶-1（PFK-1，主要限速酶）/Mg}^{2+}} \text{F-1,6-BP} + \text{ADP} + \text{H}^+\]
- **第4步：F-1,6-BP的裂解**
  \[\text{F-1,6-BP} \xrightleftharpoons{\text{醛缩酶}} \text{GAP} + \text{DHAP}\]
- **第5步：丙糖磷酸的异构化**
  \[\text{DHAP} \xrightleftharpoons{\text{丙糖磷酸异构酶}} \text{GAP}\]
  *（注：至此1分子G生成2分子GAP，后续反应均需乘以2）*

**2. 放能阶段（获能阶段，GAP 转化为 Pyr）**
- **第6步：GAP脱氢并磷酸化**
  \[\text{GAP} + \text{NAD}^+ + \text{P}_i \xrightleftharpoons{\text{3-磷酸甘油醛脱氢酶}} \text{1,3-BPG} + \text{NADH} + \text{H}^+\]
- **第7步：1,3-BPG底物水平磷酸化**
  \[\text{1,3-BPG} + \text{ADP} \xrightleftharpoons{\text{磷酸甘油酸激酶/Mg}^{2+}} \text{3-PG} + \text{ATP}\]
- **第8步：3-PG变位异构**
  \[\text{3-PG} \xrightleftharpoons{\text{磷酸甘油酸变位酶}} \text{2-PG}\]
- **第9步：2-PG脱水**
  \[\text{2-PG} \xrightleftharpoons{\text{烯醇化酶}} \text{PEP} + \text{H}_2\text{O}\]
- **第10步：PEP底物水平磷酸化（不可逆）**
  \[\text{PEP} + \text{ADP} + \text{H}^+ \xrightarrow{\text{丙酮酸激酶（限速酶）/Mg}^{2+},\text{ K}^+} \text{Pyr} + \text{ATP}\]
**糖酵解总反应式**

  \[\text{G} + 2\text{NAD}^+ + 2\text{ADP} + 2\text{P}_i \rightarrow 2\text{Pyr} + 2\text{NADH} + 2\text{H}^+ + 2\text{ATP} + 2\text{H}_2\text{O}\]
    整个途径净生成 **2 分子 \(ATP\)** 和 **2 分子 \(NADH\)**。

* **关键酶（限速酶）**：
  1. **己糖激酶（HK）** / **葡萄糖激酶（GK）**
  2. **磷酸果糖激酶-1（PFK-1）**：糖酵解中最核心、最重要的限速酶。
  3. **丙酮酸激酶（PK）**

* **生理意义**：
  1. **快速供能**：在缺氧、剧烈运动等应急状态下提供快速能量。
  2. **特殊细胞供能**：如成熟红细胞由于没有线粒体，完全依赖糖酵解供能。
  3. **提供合成代谢原料**：许多中间产物可作为其他生物合成的碳骨架原料（如 **G-6-P** 进入戊糖磷酸途径，**DHAP** 用于合成脂肪的甘油等）。
  4. **是有氧氧化的准备阶段**：生成的 **Pyr** 可进入线粒体转化为乙酰-CoA，进一步在柠檬酸循环中彻底氧化。

### Front
论述：简述糖酵解（EMP途径）的限速酶和调控方式

### Back
糖酵解共有 3 个由不可逆反应催化的限速步骤，分别由 3 个限速酶（关键酶）催化，其调控方式主要为变构调节和共价修饰调节：

#### 1. 己糖激酶（HK）与葡萄糖激酶（GK）的调控
* **己糖激酶（HK）的变构调节**：
  * **抑制剂**：受其反应产物 **\(G-6-P\)** 及 **\(ADP\)**、长链脂酰-CoA 的变构抑制。
  * **解除抑制**：无机磷酸（\(P_i\)）可以解除 \(G-6-P\) 对 HK（主要指 I 型）的抑制作用。
* **葡萄糖激酶（GK，仅存在于肝脏和胰岛 \(\beta\) 细胞）的调节**：
  * **特点**：对葡萄糖的 \(K_m\) 值高，且**不受** \(G-6-P\) 的反馈抑制。
  * **调节蛋白**：其活性受葡萄糖激酶调节蛋白（GKRP）的调节，使其定位在细胞核中阻断活性。
  * **激素调节**：受胰岛素的诱导合成。


#### 2. 磷酸果糖激酶-1（PFK-1）的调控（整个途径最核心的限速步骤）
PFK-1 是一个四聚体，受多种变构效应剂的复杂调节：
* **变构抑制剂**：
  * **高浓度 \(ATP\)**：\(ATP\) 既是底物也是变构抑制剂。高能态时，\(ATP\) 与酶的别构抑制位点结合，降低酶对底物 \(F-6-P\) 的亲和力。
  * **柠檬酸、脂肪酸**：柠檬酸和脂肪酸作为能量充足的信号，能增强 \(ATP\) 的抑制作用。
  * **\(H^+\)**：当 \(pH\) 下降（如缺氧导致乳酸堆积）时，\(H^+\) 抑制 PFK-1 活性，以阻止糖酵解继续进行，避免严重的酸中毒。
* **变构激活剂**：
  * **\(AMP\)、\(ADP\)**：能解除 \(ATP\) 的变构抑制，激活酶活性。
  * **\(2,6\)-二磷酸果糖（\(F-2,6-BP\)）**：是 PFK-1 **最强烈的别构激活剂**，可极大地增加酶与 \(F-6-P\) 的亲和力并降低 \(ATP\) 的抑制作用。
  * **协同激活**：当 \(F-1,6-BP\)、\(G-6-P\) 与 \(AMP\) 积累时，能联合产生更强的激活效应。
* **激素调控（通过 \(F-2,6-BP\) 介导）**：
  * 胰高血糖素（和肾上腺素）通过 \(cAMP\) 信号通路活化 PKA，使双功能酶磷酸化，抑制 PFK-2 并活化 FBPase-2，使 \(F-2,6-BP\) 减少，从而抑制糖酵解。胰岛素的作用相反，通过去磷酸化激活 PFK-2，增加 \(F-2,6-BP\) 浓度，激活糖酵解。

#### 3. 丙酮酸激酶（PK）的调控
* **变构调节**：
  * **前馈激活剂**：**\(F-1,6-BP\)**（前一步骤的产物变构激活 PK，使后段反应加速）。
  * **变构抑制剂**：**\(ATP\)**（能量充足信号）、**丙氨酸**、**乙酰-CoA**、**长链脂肪酸**。
* **共价修饰调节（磷酸化与去磷酸化）**：
  * 肝脏中的丙酮酸激酶（L型）受可逆磷酸化的控制。
  * **磷酸化（无活性）**：当血糖浓度降低时，胰高血糖素启动 \(cAMP-PKA\) 级联反应，使丙酮酸激酶磷酸化而失活，从而抑制肝脏中的糖酵解，节省葡萄糖以优先供应大脑等器官。
  * **去磷酸化（有活性）**：在血糖充足、胰岛素作用下，丙酮酸激酶去磷酸化恢复活性，糖酵解恢复进行。

### Front
论述：简述糖酵解产生的丙酮酸的去路及其生理意义

### Back
在不同供氧状态和生物组织中，丙酮酸主要有以下五条代谢去路：

1. **无氧下还原为乳酸（乳酸发酵）**
   * **过程与催化酶**：在缺氧时，丙酮酸在细胞质中作为 \(NADH\) 的氢受体，经**乳酸脱氢酶**催化还原为乳酸，同时使 \(NADH\) 重新氧化为 \(NAD^+\)。
   * **生理意义**：是骨骼肌剧烈运动缺氧时，以及成熟红细胞等无线粒体细胞快速获取能量的主要方式。

2. **无氧下转化为乙醇和 \(\text{CO}_2\)（乙醇发酵）**
   * **过程与催化酶**：酵母等微生物在无氧下，经**丙酮酸脱羧酶**和**乙醇脱氢酶**催化，分步将丙酮酸转化为乙醇和 \(\text{CO}_2\)。
   * **生理意义**：是某些植物和微生物无氧状态下的供能方式，广泛应用于工业发酵。

3. **有氧下氧化脱羧生成乙酰辅酶A（进入有氧氧化）**
   * **过程与催化酶**：有氧时，丙酮酸进入线粒体，在**丙酮酸脱氢酶复合体**催化下氧化脱羧生成乙酰-CoA。
   * **生理意义**：生成的乙酰-CoA 可进入柠檬酸循环彻底氧化，是有氧氧化的核心过渡步骤，也是合成脂肪酸、酮体等的重要原料。

4. **转变为丙氨酸（转氨基作用）**
   * **过程与催化酶**：通过**谷丙转氨酶**的催化，丙酮酸接受氨基转变为丙氨酸。
   * **生理意义**：联系糖代谢与氨基酸代谢，是肌肉与肝脏间“丙氨酸-葡萄糖循环”的重要环节。

5. **羧化生成草酰乙酸（糖异生与回补反应）**
   * **过程与催化酶**：丙酮酸在线粒体中经**丙酮酸羧化酶**催化生成**草酰乙酸**。
   * **生理意义**：一是作为糖异生的前体步骤以合成葡萄糖；二是作为回补反应，直接补充三羧酸循环中流失的中间产物。

### Front
论述：简述丙酮酸脱氢复合体的作用

### Back
* **定位与基本作用**：位于线粒体基质中，催化丙酮酸进入线粒体后进行氧化脱羧反应生成乙酰辅酶A（乙酰-CoA），是连接糖酵解与柠檬酸循环（TCA 循环）的枢纽反应。
* **催化反应方程式**：
  \[\text{丙酮酸} + \text{NAD}^+ + \text{CoA-SH} \rightarrow \text{乙酰-CoA} + \text{NADH} + \text{H}^+ + \text{CO}_2\]
  此反应释放出的二氧化碳是有机酸脱羧产生，生成的 \(NADH\) 进入呼吸链进行氧化磷酸化。

* **复合体的分子结构与催化分工（含有3种酶，E1为限速酶）**：
  1. E1（丙酮酸脱氢酶 / 丙酮酸脱羧酶）：催化丙酮酸脱羧生成羟乙基-TPP。这是整个复合体的**限速步骤**，以 **焦磷酸硫胺素（TPP）** 为辅酶。
  2. E2（二氢硫辛酰转乙酰酶）：催化将乙酰基从硫辛酸转移给辅酶A生成乙酰-CoA。以**硫辛酸** 和 **辅酶A（CoA-SH）** 为辅酶。
  3. E3（二氢硫辛酰脱氢酶）：催化还原型硫辛酰胺重新氧化，并将氢转移给 \(NAD^+\) 产生 \(NADH\)。以 **\(FAD\)** 和 **\(NAD^+\)** 为辅酶。
  * **5 种必需辅因子**：TPP、硫辛酸、FAD、\(NAD^+\)、CoA-SH。

* **催化活性的调节机制**：
  1. **变构调节**：
     * **别构抑制剂**：受反应产物**乙酰-CoA**、**NADH** 以及高能量信号 **ATP**、脂肪酸的变构抑制。
     * **别构激活剂**：受低能量信号 **AMP**、**ADP** 以及底物 **\(NAD^+\)** 和 **\(Ca^{2+}\)** 的别构激活。
  2. **共价修饰调节（可逆磷酸化调节 E1 活性）**：
     * **磷酸化（无活性）**：在丙酮酸脱氢酶激酶催化下，E1 蛋白发生磷酸化而失去活性。该激酶受 ATP、NADH 和乙酰-CoA 的激活。
     * **去磷酸化（有活性）**：在丙酮酸脱氢酶磷酸酶（受 \(Ca^{2+}\) 和胰岛素激活）催化下，E1 去磷酸化恢复活性，从而加速糖的有氧氧化。
