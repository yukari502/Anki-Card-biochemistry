### Front
名词解释：痛风

### Back
痛风是由于体内嘌呤核苷酸分解代谢异常，血液中尿酸含量过高引起的结晶沉积在关节等部位的疾病。临床上常用结构与次黄嘌呤相似的别嘌呤醇进行治疗，其对黄嘌呤氧化酶有很强的抑制作用，可减少尿酸生成。

---

### Front
名词解释：限制性内切酶

### Back
限制性内切酶是原核生物中存在的一类能识别外源 DNA 双螺旋中 4–8 个碱基对组成的特异具有二重旋转对称性序列，并在该序列某位点水解 DNA 双螺旋链，产生黏性末端或平末端的酶。适用于特异切割 DNA，常作为工具酶。

---
### Front
名词解释：核苷酸的补救途径

### Back
核苷酸的补救途径（又称重新利用途径）是指利用体内游离的碱基或核苷，经过简单的反应过程合成嘌呤或嘧啶核苷酸的途径。该途径能节省从头合成时能量与氨基酸的消耗，并能弥补脑、骨髓等缺乏从头合成酶体系的组织器官合成核苷酸的不足。

---

### Front
名词解释：核苷酸的从头合成

### Back
核苷酸的从头合成是指生物体内利用 5-磷酸核糖、氨基酸、一碳单位及 \(\text{CO}_2\) 等简单物质为原料，经过一系列酶促反应合成嘌呤或嘧啶核苷酸的过程。肝脏是进行从头合成的主要器官。

---

### Front
名词解释：核酸分解代谢

### Back
核酸分解代谢是指核酸在核酸酶作用下水解连接核苷酸之间的 3', 5'-磷酸二酯键生成低聚核苷酸或单核苷酸，单核苷酸进一步水解脱磷酸生成核苷，并最终分解为碱基（嘌呤或嘧啶）和戊糖的代谢过程。

---


### Front
名词解释：雷纳综合征

### Back
雷纳综合征（又称 Lesch-Nyhan 综合征或自毁容貌症）是一种因基因缺陷导致次黄嘌呤-鸟嘌呤磷酸核糖转移酶（HGPRT）完全缺失而引起的伴性遗传性疾病。缺乏该酶使次黄嘌呤和鸟嘌呤无法转变为 IMP 和 GMP，导致过量尿酸积聚，临床表现为高尿酸血症、高度智力障碍、脑源性麻痹及自伤症等。

---

### Front
名词解释：乳清酸血症

### Back
乳清酸血症（又称乳清酸尿症）是由于乳清酸磷酸核糖转移酶和乳清酸核苷脱羧酶发生缺陷，导致乳清酸不能转变为尿苷酸，几乎无法合成嘧啶类核苷酸，从而使乳清酸大量积累并出现在血液和尿液中的疾病。

---
### Front
核苷酸的生物功能

### Back
1. **作为核酸合成的前体**：为核苷酸最主要的功能（体内主要是 5'-核苷酸）。
2. **活化中间产物**：如 UDP-葡萄糖参与糖原合成，CDP-二脂酰甘油参与磷脂合成。
3. **体内能量的利用形式**：包括 ATP、GTP、UTP、CTP 等，其中 ATP 是通用的高能化合物。
4. **作为辅酶的组成成分**：腺苷酸是多种辅酶的结构成分，如 CoA、FAD、\(\text{NAD}^+\)、\(\text{NADP}^+\) 等。
5. **作为信号分子参与代谢和生理调节**：例如 cAMP 和 cGMP 作为第二信使，ATP/ADP/AMP 调节细胞代谢。
6. **细胞特殊效应的介质**：如 ppGpp 是氨基酸饥饿引起效应的中间介质。

### Front
简述嘌呤核苷酸的从头合成（包含IMP的合成与IMP的转变，注明重要底物并标明限速酶）

### Back
**一、重要底物与原料来源**
嘌呤核苷酸从头合成的主要底物和原料包括：5-磷酸核糖（R-5-P）、谷氨酰胺（Gln）、甘氨酸（Gly）、天冬氨酸（Asp）、一碳单位（甲酰基）以及 \(\text{CO}_2\)。其中嘌呤环各原子来源如下：
![alt text](/Ch.27%20核酸的降解和核苷酸的代谢/media/image.png)

**二、从头合成的具体步骤**

**1. 第一阶段：IMP（次黄嘌呤核苷酸）的合成**
*   **PRPP的生成**：5-磷酸核糖在5-磷酸核糖焦磷酸激酶（PRPP合成酶）催化下，消耗ATP生成5'-磷酸核糖-1'-焦磷酸（PRPP）。
    \[ \text{5-磷酸核糖} + \text{ATP} \xrightarrow{\text{PRPP合成酶}} \text{PRPP} + \text{AMP} \]
*   **PRA的生成（限速步骤）**：PRPP在**谷氨酰胺:磷酸核糖焦磷酸酰胺转移酶（限速酶）**催化下，由谷氨酰胺提供氨基，生成5'-磷酸核糖胺（PRA）。
    \[ \text{PRPP} + \text{谷氨酰胺} + \text{H}_2\text{O} \xrightarrow{\text{谷氨酰胺:磷酸核糖焦磷酸酰胺转移酶（限速酶）}} \text{PRA} + \text{谷氨酸} + \text{PPi} \]
*   **IMP的闭环生成**：PRA在甘氨酸、一碳单位、\(\text{CO}_2\)、天冬氨酸及谷氨酰胺的逐步参与下，历经多步反应完成嘌呤环的合成，最终生成IMP。

**2. 第二阶段：IMP转化为AMP与GMP** （**重要**）
*   **IMP转化为AMP**：
    1. IMP与天冬氨酸在腺苷酸代琥珀酸合成酶催化下，
    2. 消耗GTP生成腺苷酸代琥珀酸。
       \[ \text{IMP} + \text{天冬氨酸} + \text{GTP} \xrightarrow{\text{腺苷酸代琥珀酸合成酶}} \text{腺苷酸代琥珀酸} + \text{GDP} + \text{Pi} \]
    3. 腺苷酸代琥珀酸在腺苷酸代琥珀酸裂解酶催化下裂解生成AMP和延胡索酸。
       \[ \text{腺苷酸代琥珀酸} \xrightarrow{\text{腺苷酸代琥珀酸裂解酶}} \text{AMP} + \text{延胡索酸} \]
*   **IMP转化为GMP**：
    1. IMP在IMP脱氢酶（次黄嘌呤脱氢酶）催化下，以 \(\text{NAD}^+\) 为受氢体，脱氢氧化生成黄苷酸（XMP）。
       \[ \text{IMP} + \text{H}_2\text{O} + \text{NAD}^+ \xrightarrow{\text{IMP脱氢酶}} \text{XMP} + \text{NADH} + \text{H}^+ \]
    2. XMP在鸟苷酸合成酶（GMP合成酶）催化下，由谷氨酰胺提供氨基并消耗ATP，生成GMP。
       \[ \text{XMP} + \text{谷氨酰胺} + \text{ATP} + \text{H}_2\text{O} \xrightarrow{\text{鸟苷酸合成酶}} \text{GMP} + \text{谷氨酸} + \text{AMP} + \text{PPi} \]

### Front
简述嘧啶核苷酸的合成（包含UMP、CTP及dTMP的合成，注明主要底物、限速酶并用方程式辅助）

### Back
**一、重要底物与嘧啶环原子来源**
*   **原料底物**：\(\text{HCO}_3^-\)（或 \(\text{CO}_2\)）、谷氨酰胺（Gln）、天冬氨酸（Asp）及 5'-磷酸核糖-1'-焦磷酸（PRPP）。
*   **嘧啶环各原子来源**：
   ![alt text](/Ch.27%20核酸的降解和核苷酸的代谢/media/image2.png)

**二、嘧啶核苷酸从头合成的具体步骤**

**1. 尿嘧啶核苷酸（UMP）的合成**（记忆前两步为主）
*   **氨基甲酰磷酸的生成（动物限速步骤）**：在细胞质中，由**氨基甲酰磷酸合成酶Ⅱ（CPS-Ⅱ，动物限速酶）** 催化谷氨酰胺、\(\text{HCO}_3^-\) 和 ATP 生成氨基甲酰磷酸。
    \[ 2\text{ATP} + \text{HCO}_3^- + \text{谷氨酰胺} + \text{H}_2\text{O} \xrightarrow{\text{氨基甲酰磷酸合成酶Ⅱ（动物限速酶）}} \text{氨基甲酰磷酸} + 2\text{ADP} + \text{Pi} + \text{谷氨酸} \]
*   **氨基甲酰天冬氨酸的生成（细菌限速步骤）**：氨基甲酰磷酸在**天冬氨酸转氨基甲酰酶（ATCase，细菌限速酶）** 催化下，与天冬氨酸反应生成氨基甲酰天冬氨酸。
    \[ \text{氨基甲酰磷酸} + \text{天冬氨酸} \xrightarrow{\text{天冬氨酸转氨基甲酰酶（细菌限速酶）}} \text{氨基甲酰天冬氨酸} + \text{Pi} \]
*   **环化与氧化**：氨基甲酰天冬氨酸脱水环化生成二氢乳清酸，随后在二氢乳清酸脱氢酶催化下脱氢氧化生成乳清酸。
    \[ \text{二氢乳清酸} + \text{NAD}^+ \xrightarrow{\text{二氢乳清酸脱氢酶}} \text{乳清酸} + \text{NADH} + \text{H}^+ \]
*   **结合PRPP与脱羧生成UMP**：乳清酸在乳清酸核糖转移酶催化下与PRPP结合生成乳清酸核苷酸（OMP），再经乳清酸核苷酸脱羧酶催化脱羧生成 UMP。
    \[ \text{乳清酸} + \text{PRPP} \xrightarrow{\text{乳清酸核糖转移酶}} \text{OMP} + \text{PPi} \]
    \[ \text{OMP} \xrightarrow{\text{乳清酸核苷酸脱羧酶}} \text{UMP} + \text{CO}_2 \]
*(注：在动物体内，前三步催化酶复合为多功能酶 CAD；后两步催化酶复合为 UMP 合成酶。)*

**2. 胞嘧啶核苷酸（CTP）的合成**
UMP 经磷酸化生成 UTP，UTP 在 **CTP 合成酶** 催化下，由谷氨酰胺提供氨基并消耗 ATP 生成 CTP。
\[ \text{UTP} + \text{谷氨酰胺} + \text{ATP} + \text{H}_2\text{O} \xrightarrow{\text{CTP合成酶}} \text{CTP} + \text{谷氨酸} + \text{ADP} + \text{Pi} \]

**3. 胸腺嘧啶脱氧核苷酸（dTMP）的合成**
dUMP 在 **胸腺嘧啶核苷酸合成酶** 催化下，以 \(N^5, N^{10}\text{-甲烯四氢叶酸}\) 为甲基供体和还原当量，甲基化生成 dTMP。
\[ \text{dUMP} + N^5, N^{10}\text{-甲烯四氢叶酸} \xrightarrow{\text{胸腺嘧啶核苷酸合成酶}} \text{dTMP} + \text{二氢叶酸} \]

### Front
简述嘌呤与嘧啶核苷酸的补救合成（包含重要途径、关键酶、反应方程式及生理意义）

### Back
**一、嘌呤核苷酸的补救合成**
1. **概念与生理意义**：利用游离的嘌呤碱或嘌呤核苷合成嘌呤核苷酸。不仅可节省从头合成时的能量与氨基酸消耗，还能满足脑、骨髓等缺乏从头合成酶系的组织器官对核苷酸的需求。
2. **主要途径与关键酶（PRPP转移途径）**：
   * **腺嘌呤磷酸核糖转移酶（APRT）**：
     \[ \text{腺嘌呤} + \text{PRPP} \xrightarrow{\text{APRT}} \text{AMP} + \text{PPi} \]
   * **次黄嘌呤-鸟嘌呤磷酸核糖转移酶（HGPRT）**：
     \[ \text{次黄嘌呤} + \text{PRPP} \xrightarrow{\text{HGPRT}} \text{IMP} + \text{PPi} \]
     \[ \text{鸟嘌呤} + \text{PRPP} \xrightarrow{\text{HGPRT}} \text{GMP} + \text{PPi} \]
3. **核苷磷酸化途径（次要途径）**：由**腺苷激酶**催化腺苷发生磷酸化生成AMP。
   \[ \text{腺苷} + \text{ATP} \xrightarrow{\text{腺苷激酶}} \text{AMP} + \text{ADP} \]
4. **临床联系**：由于基因缺陷导致 HGPRT 完全缺失的患儿，会表现出自毁容貌症（Lesch-Nyhan 综合征）。

**二、嘧啶核苷酸的补救合成**
1. **主要途径（核苷磷酸化与激酶途径）**：
   * 游离尿嘧啶先经**尿磷酸化酶**转变为尿嘧啶核苷，再由**尿苷激酶**催化生成 UMP。
     \[ \text{尿嘧啶} + \text{1-磷酸核糖} \xrightarrow{\text{尿磷酸化酶}} \text{尿嘧啶核苷} + \text{Pi} \]
     \[ \text{尿嘧啶核苷} + \text{ATP} \xrightarrow{\text{尿苷激酶}} \text{UMP} + \text{ADP} \]
   * 胞嘧啶核苷由**核苷激酶**催化磷酸化生成 CMP：
     \[ \text{胞嘧啶核苷} + \text{ATP} \xrightarrow{\text{核苷激酶}} \text{CMP} + \text{ADP} \]
   * 胸腺嘧啶核苷（胸苷）由**胸苷激酶（TK）**催化生成 dTMP：
     \[ \text{胸苷} + \text{ATP} \xrightarrow{\text{胸苷激酶}} \text{dTMP} + \text{ADP} \]
2. **PRPP转移途径**：在**嘧啶磷酸核糖转移酶**催化下，嘧啶碱直接与 PRPP 反应生成嘧啶核苷酸（注：胞嘧啶不能直接利用，需先脱氨转变为尿嘧啶）。
   \[ \text{嘧啶（U、T）} + \text{PRPP} \xrightarrow{\text{嘧啶磷酸核糖转移酶}} \text{嘧啶核苷酸} + \text{PPi} \]

### Front
对比嘌呤核苷酸与嘧啶核苷酸合成的异同

### Back
**一、相同点**
1. **合成途径**：均包含从头合成（De novo pathway）与补救合成（Salvage pathway）两条途径。
2. **主要器官与细胞定位**：高等动物的主要合成器官均为肝脏，细胞内定位均在细胞质溶胶。
3. **共同原料与底物**：均需要 5-磷酸核糖（活化形式为 PRPP）、谷氨酰胺（Gln）、天冬氨酸（Asp）及 \(\text{CO}_2\)。
4. **合成策略**：均先合成一种核心中间产物核苷酸，在此基础上再衍生合成其他核苷酸。

**二、不同点比较**

| 比较项目 | 嘌呤核苷酸合成 | 嘧啶核苷酸合成 |
| :--- | :--- | :--- |
| **特异原料** | 甘氨酸（Gly）、一碳单位（甲酰基） | 一碳单位（仅合成 dTMP 时需要） |
| **合成顺序与特点** | 在 PRPP 基础上逐步装配嘌呤环，不出现游离碱基，直接生成核苷酸 | 先合成游离的嘧啶环，然后再与 PRPP 结合生成核苷酸 |
| **核心中间产物** | 次黄嘌呤核苷酸（IMP） | 尿嘧啶核苷酸（UMP） |
| **后续衍生产物** | 由 IMP 进一步转变为 AMP 和 GMP | 由 UMP 进一步转变为 CTP 和 dTMP |
| **限速酶/关键酶** | 谷氨酰胺:磷酸核糖焦磷酸酰胺转移酶（PRPP酰胺转移酶）、PRPP合成酶 | 氨基甲酰磷酸合成酶Ⅱ（CPS-Ⅱ，动物）、天冬氨酸转氨基甲酰酶（ATCase，细菌） |
| **能量消耗供体** | 消耗 ATP 与 GTP | 主要消耗 ATP |
